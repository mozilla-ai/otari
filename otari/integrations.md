# Integrations

Otari integrates with popular AI development frameworks and coding tools. Explore the integration guides to learn how to configure each tool to work with Otari, with minimal changes to your existing workflows.

- [OpenCode](https://docs.otari.ai/guides/integrations/opencode)

- [LangChain](https://docs.otari.ai/guides/integrations/langchain)
