# Framework integrations

Otari integrates with popular AI development frameworks and coding tools. By connecting your existing tools and applications to Otari, you can manage all your LLM requests and benefit from features such as usage tracking, cost management, [budgets](set-a-budget-and-ceiling.md), fallback routing, and [guardrails](manage-guardrails.md), where supported. Explore the integration guides to learn how to configure each tool to work with Otari, with minimal changes to your existing workflows.

## Supported integrations

- [Claude Code](https://docs.otari.ai/guides/agents-and-frameworks/use-with-claude-code)
- [Codex](https://docs.otari.ai/guides/agents-and-frameworks/use-with-codex)
- [Junie](https://docs.otari.ai/guides/agents-and-frameworks/use-with-junie)
- [opencode](https://docs.otari.ai/guides/agents-and-frameworks/use-with-opencode)
- [Pydantic AI](https://docs.otari.ai/guides/agents-and-frameworks/use-with-pydantic-ai)
- [LangChain](https://docs.otari.ai/guides/agents-and-frameworks/use-with-langchain)
- [LangGraph](https://docs.otari.ai/guides/agents-and-frameworks/use-with-langgraph)

Missing one? [Open an issue](https://github.com/mozilla-ai/otari/issues/new/choose).
